How to install

No Play Store — just a quick sideload. Here’s how.

  1. 1

    Download the APK

    Tap the Download for Android button above. The file is about 30 MB.

  2. 2

    Open the file

    Pull down your notifications or open your Downloads folder and tap application-fc2f963e-4fec-4489-b1f8-ad68d71c3bca.1.apk.

  3. 3

    Allow installs from this source

    Android will show a prompt asking you to allow installs from this source. Tap Settings, toggle Allow from this source, then go back.

    This is normal for any app installed outside the Play Store — nothing is wrong.

  4. 4

    Install & open

    Tap Install, wait a few seconds, then tap Open. You’re in.
